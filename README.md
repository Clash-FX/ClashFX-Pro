# ClashFX Pro

## English

This repository hosts the Sparkle auto-update feed for ClashFX Pro. It does not contain the application source code.

- ClashFX Pro is a native macOS proxy client powered by mihomo.
- This repo publishes the `appcast.xml` feed for Sparkle updates.
- GitHub Pages: https://clash-fx.github.io/ClashFX-Pro/appcast.xml
- ClashFX Pro is the paid edition of ClashFX, featuring a native SwiftUI dashboard, visual config editor, subscription management, and smart node selection.
- The free version uses a web-based dashboard (metacubexd).
- Free version: https://github.com/Clash-FX/ClashFX
